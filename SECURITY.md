# Security Policy

## Reporting a vulnerability

If you discover a security issue, please open a private security advisory on GitHub for this repository.

Include:
- Affected version/commit
- Reproduction steps
- Impact assessment
- Any suggested remediation

## Response goals

- Initial triage: within 7 days
- Remediation plan or mitigation guidance: as soon as practical based on severity

## Scope notes

- This project intentionally does not include telemetry or remote logging.
- Issues affecting native runtime dependency provenance or licensing should also be reported.
