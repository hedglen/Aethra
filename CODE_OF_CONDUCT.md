# Code of Conduct

## Our standards

Contributors are expected to be respectful, constructive, and inclusive.

Examples of expected behavior:
- Respectful technical disagreement
- Helpful code review feedback
- Clear and professional communication

Examples of unacceptable behavior:
- Harassment or discriminatory language
- Personal attacks
- Deliberate disruption of collaboration

## Enforcement

Project maintainers may remove comments, reject contributions, or block participation for behavior that violates this code of conduct.
